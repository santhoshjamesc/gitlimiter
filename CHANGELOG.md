# Changelog

## 0.1.0

First public release.

- Status bar meter: ✅ OK, 👀 getting big, 🚨 open a PR.
- Limits on files changed and lines changed per file, counted against your base branch.
- Alert with sound, a joke, and buttons to open a PR, see details, or raise limits.
- Details panel with a picture and the list of files over the limit.
- Raise limits per branch (+40%, +30%, +20%, +10%).
- Set limits per workspace or for all projects.
- Getting Started walkthrough.
